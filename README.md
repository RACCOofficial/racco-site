# RACCO GitHub Pages

1. Add your hero image as `assets/racco-hero.jpg`.
2. In `style.css`, find `.hero-image` and replace its background with:
   `background:#111 url("assets/racco-hero.jpg") center/cover no-repeat;`
3. Create a new GitHub repository, e.g. `racco-site`.
4. Upload `index.html`, `style.css` and the `assets` folder.
5. GitHub repo → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
6. GitHub gives you the public URL.
